# 符号表

`symbol-zh.tsv`：`输入码\t名字\t符号 符号 …`，随包给符号候选用（`qingjian_core::SymbolTable` 读，按输入码**完整相等**查）。

| 文件 | 来源 | 许可 |
| --- | --- | --- |
| `symbol-zh.tsv` | 青简自己整理（字符本身是 Unicode 标准字符，不受版权保护） | 与仓库一致，GPL-3.0-or-later |

## 与 emoji 表的分工

| | 查法 | 出现位置 | 覆盖不到的 |
| --- | --- | --- | --- |
| [`assets/emoji`](../emoji) | 按**候选词的文本**（笑 → 😄） | 紧跟在那个词后面 | 名字不在词库里的（`对勾` 不是词，✔ 就挂不上） |
| 本表 | 按**用户敲的输入码**（`duigou` → ✔） | 固定第 2 位 | 名字不好念的（`※` 得知道它叫「参照符号」） |

两张表都有的条目不会出两遍：名字正好是词库里的词时（`renminbi` → 人民币 → ¥），
emoji 那条路先挂上，符号这条按文本去重跳过。

## 改表的两条规矩

1. **收录标准是「按名字找得到、键盘上打不出来」**。逗号句号这类键盘直接有的不收，
   全角标点走 `[general] full_width_punctuation`，不在这里重复。
2. **输入码不能是极常用的词**。符号插在候选第 2 位，`yinwei` → ∵、`fen` → ¢ 这种
   会让正常打字每次多看一条噪音；宁可打不出也不要挡路。
   希腊字母同理，只收按拉丁名敲的（`alpha`），`pai` / `mu` 这些与常用音节撞的不收。

**一次最多出三个**（与 emoji 合起来最多四格），所以一条十个符号的（圆圈数字、罗马数字、括号数字）
第四个起就够不着了。这三类另给每个数字单独一个码：`yuanquanqi` → ⑦、`luomasi` → Ⅳ、`kuohaoshi` → ⑽；
`yuanquanshuzi` 这种总名字保留，当「看看有哪些」的入口，出前三个。
