打字方式不变，仍然按普通话拼音输入；变的只是候选窗口里显示的字与上屏的字。

## 开启

「偏好设置 → 通用 → 输出字形」，或在配置文件里写 `[general]` 的 `traditional`：

| 选项 | 配置写法 | 效果 |
|---|---|---|
| 简体 | `off` | 不转换（默认） |
| 繁体（台湾正体） | `taiwan` | 台湾字形，并按台湾用语转换：软件 → 軟體、内存 → 記憶體、鼠标 → 滑鼠 |
| 繁体（香港） | `hongkong` | 香港字形，用语不变 |
| 繁体（通用字形） | `standard` | 只换字形，用语不变：软件 → 軟件 |

台湾与香港的字形取舍不同（裡 / 裏、著 / 着），所以分开两档。改动立即生效，不必重新切换输入法。

### Linux

Linux 版没有偏好设置窗口，也不会自动读取改过的配置：改配置文件，再重启青简服务。以台湾正体为例：

```bash
sed -i 's/^traditional = .*/traditional = "taiwan"/' ~/.config/qingjian/config.toml
systemctl --user restart qingjian-server
```

把 `taiwan` 换成 `hongkong` / `standard` 就是另外两档，改回 `off` 是简体；每次改完都要重启一次服务。
IBus 与 fcitx5 两种装法都是这个文件。Flatpak 版的配置文件在 `~/.var/app/app.qingjian.Qingjian/config/qingjian/config.toml`，
重启命令相同。

## 学习数据始终是简体

词库、词频、用户词、个人常用搭配记录的都是简体。所以：

- 开着繁体输出时学到的词，改回简体输出后照样优先。
- 反过来也一样：之前用简体攒下的习惯，开繁体后立刻生效。
- 删除候选（修饰键 + 数字）删的也是那条简体记录。

## 仍按简体的拼音与用词输入

转换发生在候选与上屏这一步，词库本身没有变，因此：

- **读音按普通话**：垃圾要打 `laji`（不是台湾读音 `lese`）、企划要打 `qihua`。
- **台湾用语要靠转换得到**：想要「軟體」，打 `ruanjian`（软件）而不是 `ruanti`。词库里没有以台湾用语为词条的词。
- **一字多形的地方偶尔会错**：简体的一个字对应多个繁体字时（后 → 後 / 后、发 → 發 / 髮），转换按词判断，生僻搭配可能选错。遇到错字可以只打那一个字再选，或改用通用字形。

需要完整的台湾读音与在地词库（注音、`lese` 这类读音）时，要换一套繁体词库，那不是这个开关能解决的。
